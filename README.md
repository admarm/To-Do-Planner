# To-Do Planner V-1

## Въведение
To-Do Planner е уеб приложение за управление на задачи, което позволява на потребителите да организират своите задачи в табла (boards) и списъци (lists). Приложението поддържа функции като регистрация, влизане, създаване, редактиране и изтриване на табла, списъци и карти (cards), както и персонализиране на цветове и тъмен режим. Тази документация описва основните компоненти, структурата и функционалностите на проекта.

## Преглед на проекта
Проектът е изграден с Node.js и Express за бекенда, React за фронтенда и MySQL за базата данни. Потребителите могат да създават табла, да добавят списъци към тях и да управляват задачи (карти) в рамките на списъците. Приложението е достъпно на адрес GitHub репозиториум.

## Основни функции
- **Регистрация и влизане:** Потребителите могат да се регистрират или влизат с имейл и парола. Поддържат се само определени имейл домейни (напр. gmail.com, abv.bg).
- **Управление на табла:** Създаване, изтриване, преименуване на табла.
- **Управление на списъци:** Добавяне, изтриване, преименуване и промяна на цвета на списъци.
- **Управление на карти:** Добавяне, редактиране, изтриване и преместване на карти между списъци.
- **Тъмен режим:** Възможност за превключване между светъл и тъмен режим.
- **Адаптивен дизайн:** Интерфейсът е оптимизиран за различни устройства.

## Tech stack
### Бекенд:
- Node.js с Express за API.
- MySQL за съхранение на данни.
- CORS за разрешаване на кръстосани заявки.

### Фронтенд:
- React с React Router за навигация.
- Redux за управление на състоянието на картите.
- Axios за комуникация с API.
- Bootstrap и персонализиран CSS за стилизиране.
- react-color за избор на цвят на списъци.

### База данни:
- MySQL с таблици за потребители, табла, списъци и карти.

## Структура на проекта
Проектът е разделен на бекенд и фронтенд компоненти. Основните файлове са:

### Бекенд
- `server.js`: Основният файл на сървъра, който конфигурира Express, свързва се с MySQL и дефинира API ендпойнти за:
  - Регистрация (`/signup`) и влизане (`/login`).
  - Управление на табла (`/boards`), списъци (`/lists`) и карти (`/cards`).
  - Операции като добавяне, изтриване, редактиране и преместване.

### Фронтенд
- `App.js`: Главният компонент, който управлява навигацията, състоянието на влизане и тъмния режим.
- `Board.js`: Компонент за управление на таблата, списъците и картите. Поддържа динамично добавяне, изтриване и редактиране.
- `Login.js`: Компонент за влизане с валидация на имейл домейни.
- `Signup.js`: Компонент за регистрация с валидация на имейл домейни.
- `styles.css`: Персонализирани стилове, включително поддръжка на тъмен режим и анимации.

### База данни
Базата данни `to-dolist` съдържа следните таблици:
- **users:** Съхранява информация за потребители (имейл, парола, ID).
- **boards:** Табла, свързани с потребители чрез `userId`.
- **lists:** Списъци, свързани с табла чрез `board_id`.
- **cards:** Карти, свързани с потребители (`user_id`) и списъци (`column_name`).

## Инсталация и стартиране

### Предпоставки
- Node.js (v14 или по-нова).
- MySQL (настроен с база данни `to-dolist`).
- Git за клониране на репозиториума.

### Стъпки за инсталация
1. Клонирайте репозиториума:
    ```bash
    git clone https://github.com/admarm/To-Do-Planner.git
    cd To-Do-Planner
    ```

2. Инсталирайте бекенд зависимостите:
    ```bash
    npm install
    ```

3. Настройте MySQL:
    - Създайте база данни `to-dolist`.
    - Импортирайте SQL структурата (ако е предоставена в репозиториума).
    - Актуализирайте данните за връзка в `server.js` (хост, потребител, парола).

4. Инсталирайте фронтенд зависимостите:
    ```bash
    cd client
    npm install
    ```

5. Стартирайте бекенда:
    ```bash
    node server.js
    ```
    Сървърът ще работи на [http://localhost:5000](http://localhost:5000).

6. Стартирайте фронтенда:
    ```bash
    cd client
    npm start
    ```
    Приложението ще се отвори на [http://localhost:3000](http://localhost:3000).

## API Ендпойнти

### Потребители
- **POST /login:** Влизане с имейл и парола.
- **POST /signup:** Регистрация на нов потребител.

### Табла
- **GET /boards/user/:userId:** Извличане на всички табла за потребител.
- **POST /boards:** Създаване на ново табло.
- **DELETE /boards/:boardId:** Изтриване на табло.
- **GET /boards/:boardId:** Извличане на детайли за табло (име и списъци).
- **PUT /boards/:boardId:** Преименуване на табло.

### Списъци
- **POST /lists:** Добавяне на нов списък.
- **DELETE /lists/:id:** Изтриване на списък.
- **PUT /lists/:id:** Преименуване на списък.
- **PUT /lists/:id/color:** Промяна на цвета на списък.

### Карти
- **GET /cards/:userId/board/:boardId:** Извличане на карти за потребител и табло.
- **POST /cards:** Добавяне на нова карта.
- **PUT /cards/move:** Преместване на карти между списъци.
- **PUT /cards/rename:** Преименуване на списък за всички карти в него.
- **PUT /cards/:id:** Редактиране на карта.
- **DELETE /cards/:id:** Изтриване на карта.

## Употреба
1. **Регистрация/Влизане:** Потребителите се регистрират или влизат чрез страниците за регистрация или влизане.
2. **Избор на табло:** След влизане потребителите могат да изберат или създадат табло.
3. **Управление на списъци и карти:**
   - Добавяйте списъци чрез бутона "Add New List".
   - Добавяйте карти в списъци чрез "+ Add a card".
   - Редактирайте или изтривайте карти чрез бутоните за редакция и изтриване.
   - Променяйте цвета на списъците чрез цветовия избор.
4. **Тъмен режим:** Превключвайте между светъл и тъмен режим чрез иконата в навигацията.
